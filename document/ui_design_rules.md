# UI 设计与视觉层级规范

基于需求截图，本项目需严格遵循以下 UI 样式规则，以保证视觉风格统一：

## 1. 核心配色方案

- **主色调（活动色）**：
  - **绿色**：`#00B578`（近似值）。用于活动标签选中的背景色、补贴标签的边框与文字。
  - **红色**：`#FF4142`（近似值）。用于价格、未选中活动标签的文字与边框、“自营”徽章背景、主要操作按钮。
- **背景色**：
  - 页面大背景 / 侧边栏未选中项：浅灰色（如 `#F5F5F5` 或 `#F8F8F8`）。
  - 商品卡片背景 / 侧边栏选中项 / 内容区：纯白色 `#FFFFFF`。
- **文本颜色**：
  - 标题/重要信息：近黑色（如 `#333333`）。
  - 次要信息/侧边栏未选中：中灰色（如 `#666666` 或 `#999999`）。

## 2. 布局与组件样式细则

### 2.1 顶部 Header 区域

- **主标题**：“补贴专区”，大字号，粗体，靠左。
- **副标题/说明**：“\* 国家补贴”，小字号，红色，靠右对齐。
- **活动标签栏 (横向滚动)**：
  - **选中状态**：绿色实心背景，白色文字，无边框，高度适中，圆角呈胶囊状 (`rounded-full`)。
  - **未选中状态**：白色背景，红色边框（1px solid），红色文字，胶囊状圆角。
  - **特殊气泡**：部分标签右上角可能带有黄色小气泡（如“可叠国补”），使用绝对定位实现。

### 2.2 左侧侧边栏 (Sidebar)

- **宽度**：固定宽度（约 `80px` 或 `90px`）。
- **背景**：整体呈浅灰色。
- **单项样式**：
  - **未选中**：浅灰色背景，居中对齐，中灰色文字，正常字重。
  - **选中（活跃）**：背景变为纯白色（与右侧内容区融为一体），文字可能加深或加粗。**注意：不需要显式的“全部”选项。**

### 2.3 右侧商品卡片 (Product Card)

- **卡片容器**：纯白背景，圆角（约 `8px`），内部有一定的内边距（如 `p-3`），卡片之间有底部分隔线或细微外边距。
- **左侧图片**：正方形比例，圆角，占位清晰。
- **右侧内容**：
  - **标题行**：多行文本截断（通常最多两行）。标题开头需紧跟一个**红底白字的“自营”小徽章**，带有小圆角 (`rounded-sm`)。
  - **服务标签**：如“国家补贴”，位于标题下方，样式为绿字、绿框（1px solid）、透明背景、小圆角，字号较小。
  - **价格区域**：位于底部。采用红色大字号加粗显示整数部分，前置较小的 `¥` 符号。
  - **操作按钮**：位于右下角，使用红色背景、白色文字的胶囊按钮（如“打开京东”），或带有箭头的图形按钮。

### 2.4 全局悬浮组件

- **右侧红包挂件**：绝对定位在右侧中部，允许部分遮挡列表。
- **回到顶部按钮**：位于右下角。样式为圆形白底容器，带有轻微阴影 (`shadow-md`)，内部是一个简单的细线向上箭头图标。

## 3. 图标方案

- 采用 **`lucide-react`** 作为图标库，它提供轻量、简洁且线条感强的图标（例如使用 `ArrowUp` 作为回到顶部的图标），与截图风格完美契合。
