# 移动端商品展示与筛选页面设计文档

## 1. 需求概述

本需求旨在开发一个适配移动端的 React 页面，主要功能为展示商品列表，并支持通过品牌进行筛选。页面布局类似京东的分类页面，左侧为品牌导航栏，右侧为商品列表区。具备无限滚动（下拉加载）和回到顶部等提升用户体验的交互功能。

## 2. 技术栈与移动端优先策略

- **前端框架**: React (建议使用 Hooks 如 `useState`, `useEffect`, `useRef`, `useCallback`)
- **样式方案**: Tailwind CSS (首选) 或 CSS Modules。采用 Flexbox 进行主体布局。
- **移动端优先适配 (Mobile First)**:
  - 核心理念：**完全以移动端（如 iPhone 宽度 375px/390px）为基准进行开发**，而不是先做 PC 版再响应式缩小。
  - 适配方案：使用 `vw/vh` 或基于基准宽度的 `rem` 方案，确保在各种手机屏幕上按比例完美呈现。在 PC 浏览器查看时，页面应限制最大宽度并居中显示（类似手机模拟器效果）。

## 3. UI 布局结构设计 (参考设计图)

页面整体可以划分为以下几个主要区域：

1. **顶部区域 (Header)**:
   - 标题：“补贴专区”等字样。
   - 活动标签栏：水平滚动的标签组（如“国家补贴”、“京补合约”、“以旧换新”等）。
2. **主体内容区 (Main Content) - Flex 布局**:
   - **左侧侧边栏 (Sidebar)**: 垂直滚动的品牌列表（Apple、一加、iQOO、三星等）。选中项需有明显的高亮/指示器样式。
   - **右侧商品列表区 (Product List)**: 垂直滚动的商品卡片流。每个卡片包含商品图、标题、多重标签（自营、国家补贴）、价格和购买/抢购按钮。
3. **全局悬浮组件 (Floating Action Buttons)**:
   - **右侧中部活动入口**: 如“至高888个”的红包挂件。
   - **回到顶部按钮 (Back to Top)**: 在页面右下角，默认隐藏，滚动超过一屏时出现。

## 4. 核心功能与交互逻辑

### 4.1 数据初始化与默认状态

- **初始数据**: 页面首次加载时，不默认选中任何特定品牌，右侧商品列表展示**全部品牌**的混合商品数据。
- **初始渲染量**: 为了性能优化，首次不渲染所有数据。仅从全量商品数组中截取刚好能覆盖约 **1.5 屏幕高度** 的数据量（例如 6-8 个商品，具体取决于卡片高度）。

### 4.2 品牌筛选逻辑 (Brand Filtering)

- **触发机制**: 用户点击左侧侧边栏的某个品牌名称。
- **处理逻辑**:
  - 高亮当前点击的品牌。
  - 右侧商品列表重置滚动条到顶部。
  - 根据商品名称（或数据中的 `brandId` 字段）从总数据中过滤出对应品牌的商品，形成一个新的**商品数组**。
  - 同样应用分页加载逻辑，将过滤后的数组的首页数据（1.5屏）渲染到右侧列表中。

### 4.3 无限滚动 / 下拉触底加载 (Infinite Scroll)

- **触发条件**: 监听右侧商品列表容器（或 `window`）的 `scroll` 事件，当滚动到底部（`scrollHeight - scrollTop <= clientHeight + 阈值`）时触发加载。
- **处理逻辑**:
  - 如果当前渲染的商品数量小于当前激活数组（全量数组或筛选后的品牌数组）的总长度，则将下一批数据（例如下 6 个商品）追加到当前渲染列表中。
  - 底部可显示“加载中...”或“没有更多了”的提示状态。

### 4.4 回到顶部按钮 (Back to Top)

- **显示/隐藏逻辑**: 监听滚动事件，当 `scrollTop` > 1个手机屏幕高度（`window.innerHeight`）时，设置状态让按钮显示；反之隐藏。
- **点击交互**: 点击按钮后，通过平滑滚动 (`behavior: 'smooth'`) 将右侧商品列表的滚动条重置为 0。

## 5. 组件拆分建议 (Component Architecture)

建议在 `src/components` 下建立以下结构：

- `PageContainer` (页面顶层容器，管理全局状态如商品总数据、当前选中品牌等)
  - `Header` (顶部标题与活动标签)
  - `ContentLayout` (主体左右分栏布局)
    - `Sidebar` (左侧品牌列表，接收 `brands` 和 `onSelectBrand`)
    - `ProductList` (右侧商品列表，包含无限滚动逻辑)
      - `ProductCard` (单个商品卡片，展示图文价等)
  - `FloatingWidgets` (右侧红包挂件)
  - `BackToTop` (回到顶部按钮，接收滚动状态控制显隐)

## 6. 核心数据结构设计参考 (Mock Data)

为了后续开发顺利，建议提前构思好数据结构：

```typescript
// 商品数据结构
interface Product {
  id: string;
  name: string; // 商品标题 (如 "vivo iQOO Z10 Turbo+ 12GB+256GB")
  brand: string; // 品牌标识 (如 "iQOO")。用于精确筛选，比直接正则匹配 name 更稳健
  imageUrl: string; // 商品图 URL
  price: number; // 价格数值
  titleTags?: string[]; // 标题行内的标签 (如 ["自营"])
  featureTags?: string[]; // 标题下方的服务标签 (如 ["国家补贴"])
}

// 品牌列表数据
interface Brand {
  id: string;
  name: string; // "Apple", "一加", 等
}
```
